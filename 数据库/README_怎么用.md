## 二、怎么看教程

### 方式 1：分屏预览（推荐）

```
① 在 VS Code 里打开 .md 文件
② 按 Ctrl+K 然后按 V        ← 分屏预览
   或者 Ctrl+Shift+V          ← 全屏预览
③ 左边写/读，右边实时渲染
```

### 方式 2：Markdown Preview Enhanced 预览

```
① 打开 .md 文件
② 右键 → Markdown Preview Enhanced: Open Preview
   或者按 Ctrl+Shift+P → 输入 "Markdown Preview Enhanced"
```

**MPE 的好处**：
- 支持目录（右上角按钮）
- 代码块更好看
- 可以导出 PDF / HTML

### 方式 3：直接读源码

**Markdown 格式很简单**，直接读也没问题：

```markdown
## 这是二级标题
**这是加粗**
`这是行内代码`
```

## 四、图标约定

教程里只用三种图标：

| 图标 | 含义 |
|---|---|
| 💡 | **重点**，必须记住 |
| ⚠️ | **注意**，容易出错的地方 |
| ❌ | **常见错误**，别人踩过的坑 |

## 五、你的学习流程

```
第 1 步：VS Code 打开章节文件夹
第 2 步：Ctrl+K V 打开预览（左右分屏）
第 3 步：从上往下读
第 4 步：看到 SQL 就复制到 HeidiSQL 里跑一遍
第 5 步：做末尾的动手练习
第 6 步：卡住了问我
```

**关键**：**每看到一条 SQL，就去 HeidiSQL 里跑一遍。** 光看不会。

## 六、HeidiSQL 怎么配合

### 打开 HeidiSQL

双击桌面 `HeidiSQL` 图标。

### 连接 MySQL

```
主机名：127.0.0.1
用户：root
密码：Root@2026
端口：3306
```

点「打开」连接。

### 执行 SQL

```
① 工具栏点「新建查询」（或按 Ctrl+T）
② 粘贴 SQL
③ 按 F9 执行
④ 下方看结果
```

### 常用快捷键

| 快捷键 | 作用 |
|---|---|
| `F9` | 执行当前语句 |
| `Ctrl+T` | 新建查询标签 |
| `Ctrl+Shift+T` | 新建查询标签 |
| `F5` | 刷新 |
| `Ctrl+,` | 打开设置 |

## 八、Markdown 常用语法速查

**教程里会用到，你写笔记也用得上：**

```markdown
# 一级标题
## 二级标题
### 三级标题

**加粗文字**
*斜体文字*
`行内代码`

- 无序列表
1. 有序列表

> 引用块

[链接文字](网址)
![图片说明](图片路径)
```

**代码块：**

````markdown
```sql
SELECT * FROM employees;
```

```python
print("hello")
```
````

**表格：**

```markdown
| 列1 | 列2 |
|---|---|
| 值1 | 值2 |
```
