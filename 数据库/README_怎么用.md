# 数据库自学教程

用 HeidiSQL 在本机 MySQL 上练 SQL。前两章先查询和统计，第 03 章定义表，第 04 章操作数据。05–11 章从关联查询进阶到一个可独立运行的 SQLite 项目。完成一课的标准是能预测结果、运行 SQL、用结果自己检查。

## 快速使用

1. 按[环境说明](./_环境验证/README_环境说明.md)启动 MySQL，用 HeidiSQL 连接 `127.0.0.1:3306`。
2. 按 `Ctrl+T` 新建查询。只粘当前代码块，按 `F9` 执行编辑区。编辑区已有多段时，可选中一段按 `Ctrl+F9`。预期报错单独执行。
3. 先写下预计的行数、编号或错误码，再运行。第 04 章核对写入后按练习说明回滚。
4. 用 VS Code 的 Markdown Preview Enhanced 预览教材。教材在关键例子旁有运行路径图，可以沿箭头把每一步和 SQL、结果格对照起来。
5. 做「动手练习」时，每题下方点「展开参考答案」查看或收起。源文件里可以直接看到答案文本。

## 本机数据和初始化

| 章节 | 现有数据 | 换环境时的入口 |
|---|---|---|
| 00–01 | `students` 为自学表，基线 5 行；01 末尾的空值排序示例还用到 `c2_employees` 的奖金 | [首次初始化](00_学前准备/00_首次初始化.sql)，限 `students` 尚未存在的新环境 |
| 02 | `c2_employees` 14 行，`c2_orders` 16 行 | [第 02 章配套 SQL](02_聚合分组/00_安装配套表.sql) |
| 03 | `c3b_type_samples`、`c3c_registrations`、`c3d_` 系列共 7 表；`c3a_` 与 `c3e_` 的作业表由你创建 | [第 03 章配套 SQL](03_建表约束/00_安装配套表.sql) |
| 04 | `c4a_employees` 至 `c4e_employees` 各 9 行，另有一个空日志表 | [第 04 章配套 SQL](04_增删改/00_安装配套表.sql) |

如果表已安装，直接开始练习。换环境时，先用第 00 章脚本初始化新环境，或选中已有的 `learn` 库。再按第 02、03、04 章顺序安装配套表。只执行缺失表的建表及对应插入段，建表成功后再插入。第 03 章按脚本顺序先建父表。现有 `students` 和第 02 章的数据直接用于只读示例。

第 04 章的演示用回滚保持样本。若你主动提交了练习写入并想从头再来，可以用第 03 章学过的操作，把受影响的练习表改成一个未占用的存档名，然后在第 04 章安装脚本中只运行该表的建表和插入段。先查表确认已有记录，给存档留一份备份。
