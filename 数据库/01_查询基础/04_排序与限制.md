# 第 01 章 · 排序与限制

> 要稳定地取前几名，先说清谁排前面、分数相同谁先，再取条数。

## 学习目标

- 用一个或多个键排序，并稳定选出前 N 行。
- 用 `LIMIT` 和 `OFFSET` 取固定页面。
- 在不修改数据的前提下观察 `NULL` 的排序位置。

## 准备

```sql
USE learn;
SELECT id, name, class, score FROM students ORDER BY id;
```

用 5 行学生数据。空值实验另外用一张已有的只读演示表 `c2_employees`；只需看奖金列，分组和统计留到下一章。

## 一、给结果定顺序

```sql
SELECT id, name, score FROM students ORDER BY score DESC, id ASC;
```

结果依次为 4、1、2、3、5。`DESC` 降序，`ASC` 升序，省略方向默认为升序。可以先按成绩降序，相同再按主键升序。当前成绩未并列，再试一个实际有并列的年龄排序。

```sql
SELECT id, name, age FROM students ORDER BY age ASC, id ASC;
```

得到 2、5、1、4、3。同龄组的内部顺序由 `id` 决定。只写 `ORDER BY age` 时，这组同龄人内部顺序没有保证。没有 `ORDER BY` 时，整个结果顺序也没有保证。中文文本的先后受排序规则影响，不能假定按字节或按拼音。

计算列的别名可以直接用在 `ORDER BY`。

```sql
SELECT id, name, score / 100 AS score_ratio FROM students
ORDER BY score_ratio DESC, id;
```

## 二、先排序，再截取

```sql
SELECT id, name, score FROM students ORDER BY score DESC, id LIMIT 2;
SELECT id, name, score FROM students ORDER BY score DESC, id LIMIT 2 OFFSET 2;
SELECT id, name, score FROM students ORDER BY score DESC, id LIMIT 2 OFFSET 4;
```

| 页码 | 跳过的行 | 返回 id |
|---:|---:|---|
| 1 | 0 | 4、1 |
| 2 | 2 | 2、3 |
| 3 | 4 | 5 |

`OFFSET = (页码 - 1) × 每页条数`。MySQL 也允许 `LIMIT 2, 2`（先偏移后条数）。学习和写报告时推荐 `LIMIT 条数 OFFSET 偏移`，读起来更清楚。确定性排序能稳定同一份数据，翻页间新插入或删除仍可让偏移发生变化。

## 三、空值应该放哪边

下面利用现有奖金样本，不增删学生记录。只看有空奖金的 `id=3` 和有奖金的 `id=1`。

```sql
SELECT id, bonus FROM c2_employees WHERE id IN (1, 3) ORDER BY bonus ASC, id;
SELECT id, bonus FROM c2_employees WHERE id IN (1, 3) ORDER BY bonus DESC, id;
SELECT id, bonus FROM c2_employees WHERE id IN (1, 3) ORDER BY bonus IS NULL, bonus, id;
```

MySQL 中升序空值在前，第一条是 3、1；降序空值在后，第二条是 1、3。第三条先按 `bonus IS NULL` 排，非空得 0 排在前，缺失得 1 排在后，再对同组按金额升序。对于奖金明细，这种写法可保留空值行，又让它们集中在末尾。

## 小结

想取「前几」先写 `ORDER BY`，用唯一键打破并列，再写 `LIMIT` 和可选的 `OFFSET`。检查返回行数，也检查最先和最后的编号。

## 动手练习

### 练习 1 · 第二页

按分数从高到低，每页两人。查第二页，并说出编号。

<details>
<summary>展开参考答案</summary>

```sql
SELECT id, name, score FROM students ORDER BY score DESC, id LIMIT 2 OFFSET 2;
```

返回 2、3。

</details>

### 练习 2 · 先筛再排

查一班年龄最小的两人；同岁时按编号从小到大。

<details>
<summary>展开参考答案</summary>

```sql
SELECT id, name, age FROM students WHERE class = '一班' ORDER BY age, id LIMIT 2;
```

返回 2、5。同岁组固定按主键排。

</details>

### 练习 3 · 看看「前两行」的含义

`SELECT id FROM students LIMIT 2` 能保证返回 1、2 吗？给出按编号取前两条的写法。

<details>
<summary>展开参考答案</summary>

只限制数量，返回的编号没有保证。下面明确指定顺序。

```sql
SELECT id FROM students ORDER BY id LIMIT 2;
```

</details>
