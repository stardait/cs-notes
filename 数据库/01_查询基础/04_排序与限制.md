# 第 1 章 · 排序与限制

> 前两篇你能「选列」和「筛行」了，但结果的顺序是**数据库随便给的**——通常是插入顺序，但不保证。
>
> 这一篇解决两件事：**让结果按你要的顺序排**（`ORDER BY`），**只取前 N 条**（`LIMIT`）。

---

## 学习目标

1. 用 `ORDER BY` 排序（升序/降序）
2. 多列排序
3. 按计算列排序
4. 用 `LIMIT` 限制条数
5. 用 `LIMIT + OFFSET` 做分页
6. 知道 `NULL` 在排序中的位置

---

## 一、为什么需要排序

### 先看没排序的结果

```sql
SELECT name, score FROM students;
```

**结果**：

| name | score |
|---|---|
| 小明 | 92.50 |
| 小红 | 88.00 |
| 小刚 | 76.50 |
| 小美 | 95.00 |
| 小强 | 61.00 |

**看起来是按 id 排的，但这只是「碰巧」。**

> ⚠️ **注意**：**没写 `ORDER BY` 时，MySQL 不保证任何顺序。**
>
> 现在看起来有序，是因为数据少、恰好按主键返回。数据量大、加了索引、换版本，顺序都可能变。
>
> **需要顺序，就必须写 `ORDER BY`。**

---

## 二、ORDER BY 基本用法

### 语法

```sql
SELECT 列
FROM 表
ORDER BY 列名 [ASC|DESC];
```

| 关键字 | 含义 | 默认 |
|---|---|---|
| `ASC` | 升序（小 → 大） | ✅ 默认，可以不写 |
| `DESC` | 降序（大 → 小） | 要显式写 |

---

### 升序（默认）

```sql
SELECT name, score FROM students ORDER BY score;
```

**等价于**：

```sql
SELECT name, score FROM students ORDER BY score ASC;
```

**结果**：

| name | score |
|---|---|
| 小强 | 61.00 |
| 小刚 | 76.50 |
| 小红 | 88.00 |
| 小明 | 92.50 |
| 小美 | 95.00 |

**从小到大。**

---

### 降序

```sql
SELECT name, score FROM students ORDER BY score DESC;
```

**结果**：

| name | score |
|---|---|
| 小美 | 95.00 |
| 小明 | 92.50 |
| 小红 | 88.00 |
| 小刚 | 76.50 |
| 小强 | 61.00 |

**从大到小。**

---

### 按名字排序

```sql
SELECT name, score FROM students ORDER BY name;
```

**结果按名字的编码排序**（中文按 UTF-8 字节序，不是拼音顺序）。

> 💡 **重点**：中文排序默认按**字节编码**，不是拼音。想按拼音排要用 `ORDER BY CONVERT(name USING gbk)` 或加 `COLLATE`。**初学不用管。**

---

## 三、多列排序

### 场景

**先按班级排，同班的再按分数从高到低排。**

```sql
SELECT name, class, score FROM students
ORDER BY class, score DESC;
```

**结果**：

| name | class | score |
|---|---|---|
| 小明 | 一班 | 92.50 |
| 小红 | 一班 | 88.00 |
| 小强 | 一班 | 61.00 |
| 小美 | 二班 | 95.00 |
| 小刚 | 二班 | 76.50 |

**规则**：

```
先按第 1 列（class）排 → 一班在前，二班在后
班内再按第 2 列（score DESC）排 → 分数高的在前
```

---

### 每个列可以单独指定升降序

```sql
SELECT name, class, score FROM students
ORDER BY class ASC, score DESC;
```

| 列 | 排序方式 |
|---|---|
| `class` | 升序（一班 → 二班） |
| `score` | 降序（高 → 低） |

**写清楚 `ASC` 更易读，虽然它是默认值。**

---

## 四、ORDER BY 可以用别名（和 WHERE 不同）

### 回顾：WHERE 不能用别名

```sql
-- ❌ 报错
SELECT score * 1.2 AS 加权分 FROM students WHERE 加权分 > 100;
```

**原因**：`WHERE` 在 `SELECT` 之前执行，别名还不存在。

---

### 但 ORDER BY 可以

```sql
SELECT name, score * 1.2 AS 加权分
FROM students
ORDER BY 加权分 DESC;
```

**✅ 能跑！**

**为什么**：`ORDER BY` 在 `SELECT` **之后**执行，那时别名已经有了。

---

### 完整执行顺序

```
FROM → WHERE → SELECT → ORDER BY → LIMIT
```

| 步骤 | 做什么 | 别名可用？ |
|---|---|---|
| 1. FROM | 取表 | ❌ |
| 2. WHERE | 筛行 | ❌ |
| 3. SELECT | 选列、算别名 | ← 别名在这里产生 |
| 4. ORDER BY | 排序 | ✅ |
| 5. LIMIT | 限条数 | ✅ |

> 💡 **重点**：**记住这个顺序，你就懂了 SQL 所有「为什么这里不能用别名」的问题。**

---

## 五、按计算列排序

```sql
SELECT name, score, score * 1.2 AS 加权分
FROM students
ORDER BY score * 1.2 DESC;
```

**按「加权分」从高到低排。**

**或者直接用别名**：

```sql
SELECT name, score, score * 1.2 AS 加权分
FROM students
ORDER BY 加权分 DESC;
```

**两种写法结果一样，用别名更简洁。**

## 六、LIMIT：只取前 N 条

### 场景

**只要分数最高的 3 个人。**

```sql
SELECT name, score FROM students
ORDER BY score DESC
LIMIT 3;
```

**结果**：

| name | score |
|---|---|
| 小美 | 95.00 |
| 小明 | 92.50 |
| 小红 | 88.00 |

**注意**：`LIMIT` 必须在 `ORDER BY` **之后**。

---

### 如果不写 ORDER BY

```sql
SELECT name, score FROM students LIMIT 3;
```

**返回「随便 3 条」**——不保证是最高的、最低的、还是前 3 个。

> ⚠️ **注意**：**`LIMIT` 一定要配合 `ORDER BY`**，否则你拿到的可能是任意 3 条。

---

### LIMIT 放在最后

```sql
SELECT name, score
FROM students
WHERE score > 70
ORDER BY score DESC
LIMIT 2;
```

**执行过程**：

```
1. FROM students           → 5 行
2. WHERE score > 70        → 4 行（小强 61 被排除）
3. SELECT name, score      → 选 2 列
4. ORDER BY score DESC     → 排序
5. LIMIT 2                 → 取前 2
```

**结果**：

| name | score |
|---|---|
| 小美 | 95.00 |
| 小明 | 92.50 |

---

## 七、LIMIT + OFFSET：分页

### 场景：网页上的「第 2 页」

**每页 2 条，要第 2 页（第 3、4 条）。**

```sql
SELECT name, score FROM students
ORDER BY score DESC
LIMIT 2 OFFSET 2;
```

**结果**：

| name | score |
|---|---|
| 小红 | 88.00 |
| 小刚 | 76.50 |

---

### 语法

```sql
LIMIT 每页几条 OFFSET 跳过几条
```

**或者简写**：

```sql
LIMIT 跳过几条, 每页几条
```

**这两个等价**：

```sql
LIMIT 2 OFFSET 2    -- 推荐，更清晰
LIMIT 2, 2          -- 注意顺序是「跳过, 取几条」
```

> ⚠️ **注意**：两种写法**参数顺序相反**！这是最容易搞错的地方。
>
> `LIMIT 2 OFFSET 2` = 跳过 2 取 2
> `LIMIT 2, 2` = 跳过 2 取 2
> 看起来一样，但 `LIMIT 5, 2` = 跳过 5 取 2，而 `LIMIT 2 OFFSET 5` = 取 2 跳过 5。
>
> **统一用 `LIMIT n OFFSET m` 就不会错。**

---

### 分页公式

```python
# Python 里算分页
page = 2          # 第 2 页（从 1 开始）
page_size = 2     # 每页 2 条
offset = (page - 1) * page_size    # = 2

sql = f"SELECT * FROM students ORDER BY score DESC LIMIT {page_size} OFFSET {offset}"
```

**验证三页**：

| 页 | OFFSET | SQL | 结果 |
|---|---|---|---|
| 1 | 0 | `LIMIT 2 OFFSET 0` | 95, 92.5 |
| 2 | 2 | `LIMIT 2 OFFSET 2` | 88, 76.5 |
| 3 | 4 | `LIMIT 2 OFFSET 4` | 61 |

## 八、NULL 在排序中的位置

### 默认行为

**先造一条 NULL 数据测试**：

```sql
INSERT INTO students (name, age, class, score)
VALUES ('小测试', 18, '三班', NULL);
```

**查询**：

```sql
SELECT name, score FROM students ORDER BY score;
```

**结果**：

| name | score |
|---|---|
| 小测试 | NULL |
| 小强 | 61.00 |
| 小刚 | 76.50 |
| 小红 | 88.00 |
| 小明 | 92.50 |
| 小美 | 95.00 |

**NULL 排最前面**（在升序时）。

---

### 降序时

```sql
SELECT name, score FROM students ORDER BY score DESC;
```

**结果**：

| name | score |
|---|---|
| 小美 | 95.00 |
| 小明 | 92.50 |
| 小红 | 88.00 |
| 小刚 | 76.50 |
| 小强 | 61.00 |
| 小测试 | NULL |

**NULL 排最后。**

> 💡 **重点**：**MySQL 里 NULL 被当作「最小值」。**
>
> 升序时在最前面，降序时在最后面。
>
> （PostgreSQL 相反，NULL 当最大值——所以换数据库时要注意。）

---

### 想让 NULL 排最后（升序时）

```sql
SELECT name, score FROM students
ORDER BY score IS NULL, score;
```

**原理**：`score IS NULL` 结果是 0（false）或 1（true），`0` 排前面 → NULL 的排后面。

---

### 清理测试数据

```sql
DELETE FROM students WHERE name = '小测试';
```

## 九、常见错误

### 错误 1：LIMIT 写在 ORDER BY 前面

```sql
-- ❌ 语法错误
SELECT * FROM students LIMIT 3 ORDER BY score;
```

**报错**：

```
ERROR 1064 (42000): You have an error in your SQL syntax...
```

**正确顺序**：`ORDER BY` 在前，`LIMIT` 在后。

---

### 错误 2：LIMIT 参数顺序搞反

```sql
-- 想取前 3 条，写成了跳过 3 条
SELECT * FROM students ORDER BY score DESC LIMIT 3, 10;
```

**`LIMIT 3, 10` = 跳过 3 条取 10 条。**

**正确**：

```sql
SELECT * FROM students ORDER BY score DESC LIMIT 3;
```

---

### 错误 3：ORDER BY 列名拼错

```sql
-- ❌
SELECT name FROM students ORDER BY scroe DESC;
```

**报错**：

```
ERROR 1054 (42S22): Unknown column 'scroe' in 'order clause'
```

---

### 错误 4：以为不写 ORDER BY 就有序

```sql
-- 结果顺序不确定
SELECT name, score FROM students WHERE class = '一班';
```

**要顺序就写 `ORDER BY`。**

## 十、本章小结

### 完整语法

```sql
SELECT 列
FROM 表
WHERE 条件
ORDER BY 列 [ASC|DESC], 列2 [ASC|DESC]
LIMIT 条数 [OFFSET 跳过];
```

### 执行顺序（背下来）

```
FROM → WHERE → SELECT → ORDER BY → LIMIT
```

### 三个要点

| 要点 | 说明 |
|---|---|
| `ASC` 是默认 | 升序可以不写；`DESC` 必须写 |
| `LIMIT` 必须配 `ORDER BY` | 否则拿到的顺序是随机的 |
| 别名在 ORDER BY 可用 | 因为它在 SELECT 之后执行 |

### NULL 排序

```
升序：NULL 在最前
降序：NULL 在最后
（MySQL 把 NULL 当最小值）
```
