# 第 02 章 · 聚合函数

> 前一章问「哪些人符合条件」，这一章先问「这些人合起来是什么数」。

## 学习目标

- 用 `COUNT`、`SUM`、`AVG`、`MIN`、`MAX` 回答统计问题。
- 说明行数、非空数和非空不同值数量的区别。
- 写下平均值的分母，用空值和空结果验证统计口径。

## 准备

```sql
USE learn;
SELECT COUNT(*) AS total FROM c2_employees;
SELECT id, name, department, salary, bonus FROM c2_employees ORDER BY id;
```

`c2_employees` 有 14 行，后续各篇沿用这一份样本。缺表时看[教材首页](../README_怎么用.md)的安装说明。

## 一、聚合把多行合成一个值

```sql
SELECT SUM(salary) AS salary_total,
       AVG(salary) AS salary_average,
       MIN(salary) AS salary_min,
       MAX(salary) AS salary_max
FROM c2_employees;
```

| salary_total | salary_average | salary_min | salary_max |
|---:|---:|---:|---:|
| 184200.00 | 13157.142857 | 6600.00 | 26000.00 |

一行代表「按条件纳入的所有员工」。先筛选再统计时，`WHERE` 决定参与人员。例如最早入职年份与最晚入职年份可以用 `MIN(hire_year)` 与 `MAX(hire_year)`，工资总额就用 `SUM(salary)`。

## 二、先决定在数什么

```sql
SELECT COUNT(*) AS employees,
       COUNT(bonus) AS known_bonus,
       COUNT(DISTINCT department) AS departments
FROM c2_employees;
```

得到 `14, 10, 4`。`COUNT(*)` 数行。`COUNT(bonus)` 数奖金已记录的行，包括记录为 0 的行。`COUNT(DISTINCT department)` 数不同的非空部门值。要统计正奖金人数，可用 `WHERE bonus > 0` 先筛，再对参与行计数。

## 三、平均数的分母是谁

```sql
SELECT SUM(bonus) AS bonus_total,
       COUNT(*) AS employees,
       COUNT(bonus) AS known_bonus,
       ROUND(AVG(bonus), 2) AS average_of_known,
       ROUND(SUM(bonus) / COUNT(*), 2) AS total_per_employee
FROM c2_employees;
```

| bonus_total | employees | known_bonus | average_of_known | total_per_employee |
|---:|---:|---:|---:|---:|
| 131000.00 | 14 | 10 | 13100.00 | 9357.14 |

第一种口径是「已登记奖金员工的平均」，除以 10。第二种把已知奖金总额摊给所有员工，除以 14。如果 `NULL` 代表「尚未核算」，你不能凭这个分摊数断言全员实际奖金平均是多少。计算先用原始值，最后按报告需要用 `ROUND(…, 2)` 显示两位。

试一下筛到零行的情况。`COUNT` 返回 0，而这些求和、平均、极值函数返回 `NULL`。

```sql
SELECT COUNT(*) AS rows_found, COUNT(bonus) AS known_bonus,
       SUM(bonus) AS bonus_total, AVG(bonus) AS bonus_average,
       MIN(bonus) AS bonus_min, MAX(bonus) AS bonus_max
FROM c2_employees
WHERE id = 999;
```

## 四、整组指标旁边该写什么

下方只有一个全员平均值，却要顺便给出一个姓名。服务器没有唯一的姓名可返回，当前 `ONLY_FULL_GROUP_BY` 打开时，报 `1140`。

```sql
-- 预期错误 1140
SELECT name, AVG(salary) FROM c2_employees;
```

`WHERE` 负责决定哪些行参与统计，直接把本层的平均工资写进 `WHERE` 也会报错。

```sql
-- 预期错误 1111
SELECT name, salary FROM c2_employees WHERE salary > AVG(salary);
```

如果现在要找高于全员平均的人，可以手动分两步。先查 `AVG(salary)` 得到基线，再把核对后的阈值写进明细查询。本例工资精确到分，用 `> 13157.14` 与高于原始平均在当前数据上得到同一批员工。基线变化后应重新计算。第 05 章会用一条查询完成这件事。

```sql
SELECT id, name, salary FROM c2_employees WHERE salary > 13157.14 ORDER BY id;
```

## 小结

先写下统计对象，再选函数。遇到 `NULL`，用 `COUNT(*)` 和 `COUNT(列)` 并排验一次。看到平均数，能说出分子和分母代表什么。

## 动手练习

### 练习 1 · 两种人数放一起

找出员工总数、已知奖金人数和未录入奖金人数。用一次查询。

<details>
<summary>展开参考答案</summary>

```sql
SELECT COUNT(*) AS all_employees, COUNT(bonus) AS known,
       COUNT(*) - COUNT(bonus) AS missing
FROM c2_employees;
```

结果 `14, 10, 4`。

</details>

### 练习 2 · 技术部的工资范围

只看技术部，给出最低工资、最高工资和总工资。

<details>
<summary>展开参考答案</summary>

```sql
SELECT MIN(salary) AS low, MAX(salary) AS high, SUM(salary) AS total
FROM c2_employees WHERE department = '技术部';
```

返回 `15000.00, 26000.00, 81000.00`。

</details>

### 练习 3 · 定义一个平均数

如果奖金业务明确规定「缺失按零计算」，基线的平均奖金按哪一个分母？若缺失只是待核算呢？

<details>
<summary>展开参考答案</summary>

按零计时分母是 14，当前已知奖金总额 131000.00，均值 9357.14。待核算时应清楚写「已登记员工均值」，分母 10，或等数据补齐再报全员均值。

</details>
