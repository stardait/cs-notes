# 第 02 章 · 聚合分组综合练习

> 一张统计表里，数字看起来合理并不够。先写下这一行代表什么、哪批明细进入了计算。

## 学习目标

- 从同一批数据分别算总量、分组统计和达标组。
- 处理未知奖金、日期边界、已取消订单和并列排序。
- 用已知行数、独立查询或手算小样本交叉核对。

## 准备

```sql
USE learn;
SELECT COUNT(*) AS employees FROM c2_employees;
SELECT COUNT(*) AS orders FROM c2_orders;
```

员工 14 行，订单 16 行。每题独立，所有语句只读。对输出有顺序要求时写 `ORDER BY`。

## 动手练习

### 练习 1 · 数行、数已知、数不同

一条查询返回员工总数、有奖金记录人数、部门种类数。

<details>
<summary>展开参考答案</summary>

```sql
SELECT COUNT(*) AS employees, COUNT(bonus) AS known_bonus,
       COUNT(DISTINCT department) AS departments FROM c2_employees;
```

`14, 10, 4`。

</details>

### 练习 2 · 工资总览

显示工资总额、平均工资（两位小数）、最低与最高工资。

<details>
<summary>展开参考答案</summary>

```sql
SELECT SUM(salary) AS total_salary, ROUND(AVG(salary), 2) AS average_salary,
       MIN(salary) AS lowest, MAX(salary) AS highest FROM c2_employees;
```

`184200.00, 13157.14, 6600.00, 26000.00`。

</details>

### 练习 3 · 两种奖金均值

同时输出按有奖金记录者计算的均值，以及把已知总额分摊到所有员工的均值。

<details>
<summary>展开参考答案</summary>

```sql
SELECT ROUND(AVG(bonus), 2) AS known_average,
       ROUND(SUM(bonus) / COUNT(*), 2) AS total_per_employee FROM c2_employees;
```

`13100.00` 对应 10 人，`9357.14` 对应 14 人。若空值代表未知，报表要标清口径。

</details>

### 练习 4 · 本期所有订单

包括待付款和已取消，算订单行数及金额合计。

<details>
<summary>展开参考答案</summary>

```sql
SELECT COUNT(*) AS orders, SUM(amount) AS gross_amount FROM c2_orders;
```

16 笔，金额 20242.00。它是录入订单金额，业务上不能直接当作已完成收入。

</details>

### 练习 5 · 每个部门多少人

一部门一行，人数从多到少；并列时按这个部门最小的员工编号排序。

<details>
<summary>展开参考答案</summary>

```sql
SELECT department, COUNT(*) AS employees FROM c2_employees
GROUP BY department ORDER BY employees DESC, MIN(id);
```

技术部、人事部各 4 人，之后是市场部、财务部各 3 人。

</details>

### 练习 6 · 每个城市工资最高多少

按城市分组，输出最高工资。先看哪几个城市出现，再核对并列顺序。

<details>
<summary>展开参考答案</summary>

```sql
SELECT city, MAX(salary) AS peak FROM c2_employees
GROUP BY city ORDER BY peak DESC, city;
```

深圳 26000、北京 22000、杭州 16000、上海 12000。这里输出各城市的最大数值。

</details>

### 练习 7 · 部门和城市一起分

按部门、城市统计人数。验证结果有 10 行，并检查技术部。

<details>
<summary>展开参考答案</summary>

```sql
SELECT department, city, COUNT(*) AS employees FROM c2_employees
GROUP BY department, city ORDER BY MIN(id);
```

10 个实际组合。技术部北京和深圳各 2 人。

</details>

### 练习 8 · 每五千元分一档

只显示档位号、人数和最高工资。工资 `10000` 该落到哪个档？

<details>
<summary>展开参考答案</summary>

```sql
SELECT salary DIV 5000 AS salary_band, COUNT(*) AS employees, MAX(salary) AS peak
FROM c2_employees GROUP BY salary DIV 5000 ORDER BY salary_band;
```

五个档人数依次为 6、3、3、1、1。10000 落在档位 2，因为低端包含 10000。

</details>

### 练习 9 · 只留平均过线的部门

留平均工资严格高于 12000 的部门，并显示人数。

<details>
<summary>展开参考答案</summary>

```sql
SELECT department, COUNT(*) AS employees, ROUND(AVG(salary), 2) AS average_salary
FROM c2_employees GROUP BY department HAVING AVG(salary) > 12000
ORDER BY AVG(salary) DESC, department;
```

只有技术部，4 人、20250.00。阈值条件使用原始平均工资。

</details>

### 练习 10 · 先筛年份再筛组

只统计 2020 年及以前入职者，从中找平均工资至少 13000 的部门。哪一部门卡在边界？

<details>
<summary>展开参考答案</summary>

```sql
SELECT department, COUNT(*) AS employees, ROUND(AVG(salary), 2) AS average_salary
FROM c2_employees WHERE hire_year <= 2020
GROUP BY department HAVING AVG(salary) >= 13000
ORDER BY AVG(salary) DESC, department;
```

技术部 24000、财务部 13500、市场部 13000。市场部刚好达标。

</details>

### 练习 11 · 看所有订单类别

把所有订单按类别统计笔数与金额，先猜金额最高的是哪一类。

<details>
<summary>展开参考答案</summary>

```sql
SELECT category, COUNT(*) AS orders, SUM(amount) AS gross_amount
FROM c2_orders GROUP BY category ORDER BY gross_amount DESC, category;
```

家电 8699、数码 7998、服饰 2540、食品 1005。总金额从上到下逐项相加，应等于第 4 题。

</details>

### 练习 12 · 只看已完成订单

实际报表只看已完成。保留该口径下金额至少 2000 的类别，按金额排序。

<details>
<summary>展开参考答案</summary>

```sql
SELECT category, COUNT(*) AS orders, SUM(amount) AS completed_amount
FROM c2_orders WHERE status = '已完成'
GROUP BY category HAVING SUM(amount) >= 2000
ORDER BY completed_amount DESC, category;
```

家电 3 笔 7800，数码 3 笔 7299，服饰 2 笔 2090。食品的已完成金额 855，未过门槛。

</details>

## 小结

验算时先问行数和分组粒度，再核对金额。若答案不同，先把查询拆成明细筛选、分组统计、组过滤三步，找到第一处偏差。
