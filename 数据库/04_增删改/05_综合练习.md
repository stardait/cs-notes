# 第 04 章 · 增删改综合练习

> 每一题先写下你预计动哪几行，再用 SQL 证实。能写出语句和能验证结果，是两项技能。

## 学习目标

- 独立完成单表插入、更新、删除和软删除。
- 做对有同名、并列和日期边界的业务题。
- 在保留初始练习数据的前提下，做一次删除和备份回放验收。

## 动手练习

### 练习 1 · 插一行

新增 `N201` 钱晓，行政部，工资 6200 元，入职日 2026-10-19。等级、状态和创建时间由表填写。

<details>
<summary>展开参考答案</summary>

```sql
START TRANSACTION;
INSERT INTO c4e_employees (employee_no, name, department, salary, hired_on)
VALUES ('N201', '钱晓', '行政部', 6200.00, '2026-10-19');
SELECT employee_no, grade, status, created_at IS NOT NULL AS has_time
FROM c4e_employees WHERE employee_no = 'N201';
ROLLBACK;
```

预期 `N201, C, active, 1`。

</details>

### 练习 2 · 批量插入

一次写入 `N202`、`N203` 两个员工，部门均为技术部，同一天入职。两人分别给定等级 B 和默认等级，工资各自填写。

<details>
<summary>展开参考答案</summary>

```sql
START TRANSACTION;
INSERT INTO c4e_employees (employee_no, name, department, grade, salary, hired_on)
VALUES ('N202', '王星', '技术部', 'B', 7200.00, '2026-10-19'),
       ('N203', '刘鑫', '技术部', DEFAULT, 6800.00, '2026-10-19');
SELECT ROW_COUNT() AS inserted;
SELECT employee_no, grade, salary FROM c4e_employees
WHERE employee_no IN ('N202', 'N203') ORDER BY employee_no;
ROLLBACK;
```

插入 2 行，等级依次 B、C。

</details>

### 练习 3 · 拿到系统编号

用系统分配的主键插入 `N204`，然后只用新主键查看自己的新行。

<details>
<summary>展开参考答案</summary>

```sql
START TRANSACTION;
INSERT INTO c4e_employees (employee_no, name, department, salary, hired_on)
VALUES ('N204', '王雨', '市场部', 6100.00, '2026-10-19');
SELECT LAST_INSERT_ID() AS new_id;
SELECT id, employee_no, name FROM c4e_employees WHERE id = LAST_INSERT_ID();
ROLLBACK;
```

编号随执行历史变化，应与第一条查询给出的新主键一致，记录是 `N204` 王雨。

</details>

### 练习 4 · 修改一列

将 `E004` 的工资改成 9500 元。确认仅有一行原工资是 9000 的目标。

<details>
<summary>展开参考答案</summary>

```sql
START TRANSACTION;
SELECT id, salary FROM c4e_employees WHERE employee_no = 'E004';
UPDATE c4e_employees SET salary = 9500.00 WHERE employee_no = 'E004';
SELECT ROW_COUNT() AS changed_rows;
SELECT id, salary FROM c4e_employees WHERE employee_no = 'E004';
ROLLBACK;
```

`id=4`，工资变为 9500，影响 1 行。

</details>

### 练习 5 · 同时修改多列

把 `id=8` 调到市场部，同时等级从 C 改成 B。工资保留。

<details>
<summary>展开参考答案</summary>

```sql
START TRANSACTION;
SELECT id, department, grade, salary FROM c4e_employees WHERE id = 8;
UPDATE c4e_employees SET department = '市场部', grade = 'B' WHERE id = 8;
SELECT ROW_COUNT() AS changed_rows;
SELECT id, department, grade, salary FROM c4e_employees WHERE id = 8;
ROLLBACK;
```

结果 `8, 市场部, B, 5000.00`。

</details>

### 练习 6 · 用原值算

行政部在职员工工资加 8%。预览要能看出同部门的离职员工不会变。

<details>
<summary>展开参考答案</summary>

```sql
START TRANSACTION;
SELECT id, status, salary FROM c4e_employees WHERE department = '行政部' ORDER BY id;
SELECT id, salary FROM c4e_employees WHERE department = '行政部' AND status = 'active';
UPDATE c4e_employees SET salary = salary * 1.08
WHERE id = 8 AND department = '行政部' AND status = 'active';
SELECT ROW_COUNT() AS changed_rows;
SELECT id, salary FROM c4e_employees WHERE id IN (6, 8) ORDER BY id;
ROLLBACK;
```

6 保持 5000，8 改为 5400。

</details>

### 练习 7 · 规则分级

市场部在职员工加薪。A 级加 500 元，B 级加 300 元，其他等级不变。说明为什么有两行符合 `WHERE`，却只有一行工资改变。

<details>
<summary>展开参考答案</summary>

```sql
START TRANSACTION;
SELECT id, grade, salary FROM c4e_employees
WHERE department = '市场部' AND status = 'active' ORDER BY id;
UPDATE c4e_employees SET salary = CASE grade
    WHEN 'A' THEN salary + 500.00
    WHEN 'B' THEN salary + 300.00
    ELSE salary
END
WHERE department = '市场部' AND status = 'active';
SELECT ROW_COUNT() AS affected;
SELECT id, salary FROM c4e_employees WHERE id IN (4, 5, 9) ORDER BY id;
ROLLBACK;
```

4 从 9000 到 9500，9 走 `ELSE` 仍是 5000，5 已离职保持 7000。默认连接报告实际变更 1 行。配置为报告匹配行的客户端可能显示 2。

</details>

### 练习 8 · 精确删除

按工号删除已离职的 `E006`。确认删除前后的总行数。

<details>
<summary>展开参考答案</summary>

```sql
START TRANSACTION;
SELECT id, employee_no, status FROM c4e_employees WHERE employee_no = 'E006' AND status = 'left';
SELECT COUNT(*) AS rows_before FROM c4e_employees;
DELETE FROM c4e_employees WHERE employee_no = 'E006' AND status = 'left';
SELECT ROW_COUNT() AS deleted;
SELECT COUNT(*) AS rows_after FROM c4e_employees;
ROLLBACK;
```

目标 6，共删除 1 行，表内由 9 行变为 8 行。

</details>

### 练习 9 · 软删后的查询

归档 `E005`。写两次查询，证明它的档案仍在，但日常查询会排除它。

<details>
<summary>展开参考答案</summary>

```sql
START TRANSACTION;
SELECT id, deleted_at FROM c4e_employees WHERE employee_no = 'E005';
UPDATE c4e_employees SET deleted_at = CURRENT_TIMESTAMP
WHERE employee_no = 'E005' AND status = 'left' AND deleted_at IS NULL;
SELECT ROW_COUNT() AS archived;
SELECT id, deleted_at IS NOT NULL AS is_archived FROM c4e_employees WHERE employee_no = 'E005';
SELECT id FROM c4e_employees WHERE employee_no = 'E005' AND deleted_at IS NULL;
ROLLBACK;
```

普通查得到 `(5, 1)`，带未归档条件的查询返回零行。

</details>

### 练习 10 · 业务题：新档案、转岗和撤消

模拟人事调整。先录入新员工 `N210` 进入技术部，再把原来三名在职技术部员工转到市场部，同时原工资下调 5%。最后模拟新员工报到取消，删除刚录入的那一行。新员工与离职档案都不该被转岗。

<details>
<summary>展开参考答案</summary>

```sql
START TRANSACTION;
SELECT id, salary FROM c4e_employees
WHERE department = '技术部' AND status = 'active' ORDER BY id;
INSERT INTO c4e_employees (employee_no, name, department, salary, hired_on)
VALUES ('N210', '乔星', '技术部', 5500.00, '2026-10-19');
UPDATE c4e_employees SET department = '市场部', salary = salary * 0.95
WHERE id IN (1, 2, 3) AND department = '技术部' AND status = 'active';
SELECT ROW_COUNT() AS transferred;
SELECT id, employee_no, department, salary FROM c4e_employees
WHERE id IN (1, 2, 3, 7) OR employee_no = 'N210' ORDER BY id;
DELETE FROM c4e_employees WHERE employee_no = 'N210';
SELECT ROW_COUNT() AS cancelled;
SELECT COUNT(*) AS remaining FROM c4e_employees;
ROLLBACK;
```

转岗 3 人，新工资 9500、7600、5700。7 号仍在技术部且工资不变。`N210` 先保留技术部与原工资，随后只删除它一行，表总行数回到 9。

</details>

### 练习 11 · 业务题：备份、清理、回放

清理 2023 年前入职且已离职的员工。先找编号并按上一课方式导出这些完整数据，再删除和复查。回放备份，证明能恢复目标。

<details>
<summary>展开参考答案</summary>

预览后，目标是 `id=5, 7`。复用[上一课第三节的导出命令](04_安全操作习惯.md)，把导出文件名前缀和末尾表名都改为 `c4e_employees`，保留主键筛选。导出成功并核对两条数据记录后，在同一个 HeidiSQL 查询标签运行下方代码。

```sql
START TRANSACTION;
SELECT id, employee_no, status, hired_on FROM c4e_employees
WHERE status = 'left' AND hired_on < '2023-01-01' ORDER BY id;
DELETE FROM c4e_employees
WHERE id IN (5, 7) AND status = 'left' AND hired_on < '2023-01-01';
SELECT ROW_COUNT() AS deleted;
SELECT id FROM c4e_employees WHERE status = 'left' ORDER BY id;
```

应删除 2 行。6 号日期为 `2023-01-01`，正好在界线，当天入职不属于「以前」。如果删除结果吻合，确认 `id=5, 7` 及对应工号已不存在，在同一个标签里选中执行自己导出文件中这两条 `INSERT INTO`，再运行下方复查。两条语句的新目标必须都是 `c4e_employees`。

```sql
SELECT id, employee_no, status, hired_on FROM c4e_employees WHERE id IN (5, 6, 7) ORDER BY id;
SELECT COUNT(*) AS rows_after_replay FROM c4e_employees;
ROLLBACK;
```

回放后查得 5、6、7，表总行数回到 9。最后回滚整个演练。排查中任何一步失败，执行 `ROLLBACK;` 并从导出及预览重新检查。

</details>

### 练习 12 · 思考题：括号改变的是谁

目标是技术部或市场部的在职人员。把条件写成 `department = '技术部' OR department = '市场部' AND status = 'active'` 会误选谁？写一种清晰的改法。

<details>
<summary>展开参考答案</summary>

`AND` 优先，所以每位技术部员工都入选，离职的 7 号也被选中。下面两处条件缺一不可。

```sql
SELECT id FROM c4e_employees
WHERE department IN ('技术部', '市场部') AND status = 'active' ORDER BY id;
```

正确编号为 1、2、3、4、9。

</details>
