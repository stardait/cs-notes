# 第 09 章 · 连接、游标与参数

> 把一条在 HeidiSQL 里已经验证的查询交给 Python，变化的是怎么发、怎么取，结果仍能逐行核对。

## 学习目标

- 解释连接、游标、execute 和 fetchall 四个步骤。
- 用 SQLite 的 ? 和 PyMySQL 的 %s 传递值。
- 能读出连接失败、表不存在和返回零行的区别。

## 准备

用本机 Python。SQLite 路线使用 Python 3.12 及以上的 `sqlite3`，样本表用 SQLite 3.37 及以上的 `STRICT`。MySQL 路线需 PyMySQL，并先运行[配套 SQL](00_安装配套表.sql)。在 PowerShell 打开本章目录。
```powershell
python .\notes_lab.py init
python .\notes_lab.py list --min 30
```

## 一、先明确 Python 在哪一层

SQLite 在 Python 进程里直接打开一个数据库文件。MySQL 的 Python 驱动通过连接把 SQL 交给服务器。两条路线的查询结构相同，连接设置和占位符不同。`init` 创建当前目录的 `c9_notes.sqlite3`，只初始化两条样本；后续 `list` 要求文件已经存在，路径写错会报错。

运行上面的命令，预期看到下面这一行。

```text
2 | 多表查询 | 35 分钟
```

先阅读[可运行示例 notes_lab.py](notes_lab.py)里的 `fetch_notes`。`connection.cursor()` 给你一个用于执行和取结果的游标。`execute` 发送或执行一条语句，`fetchall` 把结果行取完，循环解包一行三个值。小结果可以一次取完，数据多时可用游标迭代或分批处理。

## 二、值通过参数通道传递

SQLite 的短版核心如下。先运行准备段初始化文件，再在本章目录启动 Python 或保存 Python 代码执行。

```python
from contextlib import closing
from pathlib import Path
import sqlite3

path = Path("c9_notes.sqlite3").resolve()
with closing(sqlite3.connect(path.as_uri() + "?mode=ro", uri=True)) as conn:
    with closing(conn.cursor()) as cur:
        cur.execute(
            "SELECT id, title, minutes FROM c9_notes WHERE minutes >= ? ORDER BY id",
            (30,),
        )
        print(cur.fetchall())
```

返回 `[(2, '多表查询', 35)]`。`(30,)` 末尾的逗号用于构造单元素元组。把筛选值改为 100 会得到空列表，说明语句成功且没匹配行。如果点错文件路径，本例的 `mode=ro` 报连接错误。若文件存在但没有那张表，通常在 `execute` 处发现问题。

换 MySQL 后由 PyMySQL 使用 `%s`。它同样接受数据作为 `execute` 的第二个参数。示例的 f-string 只选择代码里固定的占位符，用户值走参数传递。

```powershell
python .\notes_lab.py --engine mysql list --min 30
```

输入本机密码，初始样本也返回 2 号。若账号不是 `root`，在 `list` 前加 `--mysql-user 你的用户`。密码由提示框读取。

| 驱动 | 值占位符 | 参数示例 |
|---|---|---|
| Python `sqlite3` | `?` | `(30,)` |
| PyMySQL | `%s` | `(30,)` |

请把占位符留在 SQL 里，直接给参数数值或字符串。把名字、路径或引号拼进 SQL 会导致边界错误。表名、列名属于 SQL 结构，不能当值占位；若查询允许选择排序列，就把允许的列名写在代码白名单，按选项挑选。

可查 [Python sqlite3 文档](https://docs.python.org/3/library/sqlite3.html)。

## 动手练习

### 练习 1 · 单个参数少一个逗号

SQLite 里第二个参数写成 `(30)` 会怎样？

<details>
<summary>展开参考答案</summary>

`(30)` 是整数，`(30,)` 才是一个元素的元组。驱动要求可供绑定的参数序列。

</details>

### 练习 2 · 名字包含单引号

如果用户输入 `O'Reilly`，按名字等值查应该怎样写 SQLite 查询？

<details>
<summary>展开参考答案</summary>

```python
cur.execute("SELECT id FROM c9_notes WHERE title = ?", ("O'Reilly",))
```

原样传入值，驱动负责参数处理。

</details>
