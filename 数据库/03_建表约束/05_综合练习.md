# 第 03 章 · 建表与约束综合练习

> 每建一张表，都能说出它守住了哪条规则，以及用什么样本证明规则生效。

## 学习目标

- 把需求翻译成列、类型和约束。
- 修改结构后用命令验收，避开属性被意外放宽的问题。
- 给一对多、多对多各设计一份结构，用边界数据验收。

## 准备

在 HeidiSQL 中执行 `USE learn;`。这组题只使用 `c3e_` 表名，由你动手建。第 6～8 题依赖第 3 题，其余可独立完成。每题先自己写，至少用 `DESCRIBE`、`SHOW CREATE TABLE` 或一个正反样本检查。

## 动手练习

### 练习 1 · 只有表头

建 `c3e_reading_notes`，记录笔记日期 `noted_on`、主题 `topic` 和正文 `body`。主题上限 60 字符，正文长短不定，暂不加业务约束。

<details>
<summary>展开参考答案</summary>

```sql
CREATE TABLE c3e_reading_notes (
    noted_on DATE,
    topic VARCHAR(60),
    body TEXT
);
DESCRIBE c3e_reading_notes;
```

结构中应有日期、短文本、长文本三列。

</details>

### 练习 2 · 生成编号

建 `c3e_bookmarks`，每条书签自动发一个整数编号，标题最多 80 字符且必填。插两条，检查能不能区分两条同名书签。

<details>
<summary>展开参考答案</summary>

```sql
CREATE TABLE c3e_bookmarks (
    id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(80) NOT NULL
) ENGINE=InnoDB;
INSERT INTO c3e_bookmarks (title) VALUES ('数据库笔记'), ('数据库笔记');
SELECT id, title FROM c3e_bookmarks ORDER BY id;
```

两条标题相同，主键不同。

</details>

### 练习 3 · 必填与默认值

建 `c3e_tasks`，含整数主键 `id`，必填标题 `title VARCHAR(60)`，必填状态 `status VARCHAR(12)` 默认 `pending`。插入时只给编号和标题，预测第三列。

<details>
<summary>展开参考答案</summary>

```sql
CREATE TABLE c3e_tasks (
    id INT PRIMARY KEY,
    title VARCHAR(60) NOT NULL,
    status VARCHAR(12) NOT NULL DEFAULT 'pending'
) ENGINE=InnoDB;
INSERT INTO c3e_tasks (id, title) VALUES (1, '复习约束');
SELECT status FROM c3e_tasks WHERE id = 1;
```

返回 `pending`。留下该表给第 6～8 题。

</details>

### 练习 4 · 必填编号与选填邮箱

建 `c3e_contacts`，内部整数 `id` 为主键，业务号 `contact_code` 最多 12 字符、必填且唯一，邮箱最长 100 字符、可空且唯一。用两行缺省邮箱检验。

<details>
<summary>展开参考答案</summary>

```sql
CREATE TABLE c3e_contacts (
    id INT PRIMARY KEY,
    contact_code VARCHAR(12) NOT NULL UNIQUE,
    email VARCHAR(100) UNIQUE
) ENGINE=InnoDB;
INSERT INTO c3e_contacts (id, contact_code) VALUES (1, 'C001'), (2, 'C002');
SELECT COUNT(*) AS missing_email FROM c3e_contacts WHERE email IS NULL;
```

返回 2。没有邮箱是允许的，有邮箱时仍要求唯一。

</details>

### 练习 5 · 业务上限

建 `c3e_ratings`，用整数主键，评分 `rating` 只接受 1 到 5 的整数，缺失也拒绝。先试 5，再试 6。

<details>
<summary>展开参考答案</summary>

```sql
CREATE TABLE c3e_ratings (
    id INT PRIMARY KEY,
    rating TINYINT NOT NULL CHECK (rating BETWEEN 1 AND 5)
) ENGINE=InnoDB;
INSERT INTO c3e_ratings (id, rating) VALUES (1, 5);
```

```sql
-- 预期错误 3819
INSERT INTO c3e_ratings (id, rating) VALUES (2, 6);
```

写入 5 成功，6 超出了业务规则。

</details>

### 练习 6 · 加一列

给第 3 题的表加一个可空截止日期 `due_on`。第 3 题的旧行会看到什么？

<details>
<summary>展开参考答案</summary>

```sql
ALTER TABLE c3e_tasks ADD COLUMN due_on DATE;
SELECT id, due_on FROM c3e_tasks WHERE id = 1;
```

旧行的 `due_on` 是 `NULL`，没有指定截止日期。

</details>

### 练习 7 · 扩大长度

把 `c3e_tasks` 的 `title` 上限改成 120 字符，必须保留原有必填规则。

<details>
<summary>展开参考答案</summary>

```sql
ALTER TABLE c3e_tasks MODIFY COLUMN title VARCHAR(120) NOT NULL;
DESCRIBE c3e_tasks;
```

检查 `title` 的 `Type` 和 `Null`，应看到 `varchar(120)` 和 `NO`。

</details>

### 练习 8 · 去掉截止日期

团队确认不需要截止日期。删除第 6 题新增的列，确认任务行仍在。

<details>
<summary>展开参考答案</summary>

```sql
ALTER TABLE c3e_tasks DROP COLUMN due_on;
DESCRIBE c3e_tasks;
SELECT COUNT(*) AS tasks_remaining FROM c3e_tasks;
```

`due_on` 消失，行数仍是 1。将来若这列已有日期，删列会一并移除它们。

</details>

### 练习 9 · 一个仓库多件货品

建 `c3e_warehouses` 与 `c3e_stock_items`。每件货品必须属于已存在的仓库，仓库里有货品时应拒绝删除仓库。自行选列名并验证删除失败。

<details>
<summary>展开参考答案</summary>

```sql
CREATE TABLE c3e_warehouses (
    id INT PRIMARY KEY,
    name VARCHAR(40) NOT NULL
) ENGINE=InnoDB;
CREATE TABLE c3e_stock_items (
    id INT PRIMARY KEY,
    warehouse_id INT NOT NULL,
    name VARCHAR(40) NOT NULL,
    FOREIGN KEY (warehouse_id) REFERENCES c3e_warehouses (id) ON DELETE RESTRICT
) ENGINE=InnoDB;
INSERT INTO c3e_warehouses (id, name) VALUES (1, '一号仓');
INSERT INTO c3e_stock_items (id, warehouse_id, name) VALUES (10, 1, '台灯');
```

```sql
-- 预期错误 1451
DELETE FROM c3e_warehouses WHERE id = 1;
```

引用放在多的一侧。仓库可有多件货，外键列保持可重复。

</details>

### 练习 10 · 图书和标签

一本书可有多个标签，标签可用于多本书。建 `c3e_books`、`c3e_tags`、`c3e_book_tags`，验证同一配对不能重复。

<details>
<summary>展开参考答案</summary>

```sql
CREATE TABLE c3e_books (id INT PRIMARY KEY, title VARCHAR(80) NOT NULL) ENGINE=InnoDB;
CREATE TABLE c3e_tags (id INT PRIMARY KEY, label VARCHAR(30) NOT NULL UNIQUE) ENGINE=InnoDB;
CREATE TABLE c3e_book_tags (
    book_id INT NOT NULL,
    tag_id INT NOT NULL,
    PRIMARY KEY (book_id, tag_id),
    FOREIGN KEY (book_id) REFERENCES c3e_books (id),
    FOREIGN KEY (tag_id) REFERENCES c3e_tags (id)
) ENGINE=InnoDB;
INSERT INTO c3e_books (id, title) VALUES (1, 'SQL 入门');
INSERT INTO c3e_tags (id, label) VALUES (1, '工具'), (2, '数据库');
INSERT INTO c3e_book_tags (book_id, tag_id) VALUES (1, 1), (1, 2);
```

```sql
-- 预期错误 1062
INSERT INTO c3e_book_tags (book_id, tag_id) VALUES (1, 1);
```

同一本书可以带两个不同标签，重复的组合会被拦住。

</details>

### 练习 11 · 字符串还是数

商品编码 `000806` 要保留原样，库存差额可能是负数，单价最高 50,000 元并精确到分。为三个字段选类型。

<details>
<summary>展开参考答案</summary>

六位定长编码可用 `CHAR(6)`，固定长度还可用额外规则验收。库存差额可用有符号 `INT`，前提是最大调整量在范围内。单价用 `DECIMAL(7,2)`，可保存五位整数和两位小数。

</details>

### 练习 12 · 学生选课

从零设计学生、课程、选课三张 `c3e_` 表。同一学生同一课程只能选一次，选课时间自动记录，最终成绩可以暂缺且有值时必须在 0 到 100。

<details>
<summary>展开参考答案</summary>

```sql
CREATE TABLE c3e_learners (
    id INT PRIMARY KEY,
    name VARCHAR(30) NOT NULL
) ENGINE=InnoDB;
CREATE TABLE c3e_courses (
    id INT PRIMARY KEY,
    title VARCHAR(80) NOT NULL
) ENGINE=InnoDB;
CREATE TABLE c3e_enrollments (
    learner_id INT NOT NULL,
    course_id INT NOT NULL,
    enrolled_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    final_score DECIMAL(5,2) CHECK (final_score BETWEEN 0 AND 100),
    PRIMARY KEY (learner_id, course_id),
    FOREIGN KEY (learner_id) REFERENCES c3e_learners (id),
    FOREIGN KEY (course_id) REFERENCES c3e_courses (id)
) ENGINE=InnoDB;
INSERT INTO c3e_learners (id, name) VALUES (1, '林青');
INSERT INTO c3e_courses (id, title) VALUES (10, '数据库基础');
INSERT INTO c3e_enrollments (learner_id, course_id) VALUES (1, 10);
SELECT learner_id, course_id, enrolled_at IS NOT NULL AS has_time, final_score
FROM c3e_enrollments;
```

预期是 `(1, 10, 1, NULL)`。再试一个不存在的课程号，外键应拒绝。

```sql
-- 预期错误 1452
INSERT INTO c3e_enrollments (learner_id, course_id) VALUES (1, 99);
```

如果业务允许同一课程在不同学期重修，要引入开课批次或学期，重新定义「重复选课」。

</details>

## 小结与重做

过关标准是说清每张表代表什么、哪一列或哪几列唯一、哪些输入该失败。保留表就能留下自己的作业。若想从第一题重做，先确认下面列出的都是自己的可清理练习表，再按子表优先的顺序运行。

```sql
DROP TABLE IF EXISTS c3e_enrollments;
DROP TABLE IF EXISTS c3e_learners;
DROP TABLE IF EXISTS c3e_courses;
DROP TABLE IF EXISTS c3e_book_tags;
DROP TABLE IF EXISTS c3e_books;
DROP TABLE IF EXISTS c3e_tags;
DROP TABLE IF EXISTS c3e_stock_items;
DROP TABLE IF EXISTS c3e_warehouses;
DROP TABLE IF EXISTS c3e_ratings;
DROP TABLE IF EXISTS c3e_contacts;
DROP TABLE IF EXISTS c3e_tasks;
DROP TABLE IF EXISTS c3e_bookmarks;
DROP TABLE IF EXISTS c3e_reading_notes;
```
