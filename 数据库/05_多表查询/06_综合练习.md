# 第 05 章 · 综合练习

> 连接练到能算清一笔订单为什么出现两次，以及它该不该被算两次。

## 学习目标

- 按客户、订单、明细三个粒度分别统计。
- 依题意处理空匹配、时间并列、订单状态和游客。

## 准备

继续复用[本章配套表](00_安装配套表.sql)。先选中 `learn`。下列题各自独立。涉及营收时只统计已付款订单，默认纳入游客，金额使用成交价乘数量。
```sql
USE learn;
```

## 先核对作答口径

「从未下单」与「没有已付款订单」是不同问题。若题目说注册客户，游客订单不计入客户分母。若题目说最新一单，时间并列时还要写上订单号规则。每道题先写下输出的一行代表什么，再运行查询。复购题用到 `NULLIF(a, b)`，两者相等返回 `NULL`，不相等则返回 `a`。

## 小结

先确定行粒度与参与范围，再决定保留没匹配的记录、去重或计入游客。

## 动手练习

### 练习 1 · 显示订单客户名

查出 101 至 103 的订单号和客户名。

<details>
<summary>展开参考答案</summary>

```sql
SELECT o.id, c.name FROM c5_orders AS o
JOIN c5_customers AS c ON c.id = o.customer_id
WHERE o.id BETWEEN 101 AND 103 ORDER BY o.id;
```

依次为林青、林青、周宁。

</details>

### 练习 2 · 从未下单

保留客户侧，找没有任何订单的人。

<details>
<summary>展开参考答案</summary>

```sql
SELECT c.id, c.name FROM c5_customers AS c
LEFT JOIN c5_orders AS o ON o.customer_id = c.id
WHERE o.id IS NULL ORDER BY c.id;
```

只有客户 5。取消订单也算曾经下单。

</details>

### 练习 3 · 一单多个商品

列出 105 的明细序号、商品名和每条成交金额。

<details>
<summary>展开参考答案</summary>

```sql
SELECT i.line_no, p.name, i.quantity * i.unit_price AS line_total
FROM c5_orders AS o
JOIN c5_order_items AS i ON i.order_id = o.id
JOIN c5_products AS p ON p.id = i.product_id
WHERE o.id = 105 ORDER BY i.line_no;
```

键盘 105.00，咖啡豆 65.00，茶包 40.00。

</details>

### 练习 4 · 每类商品的营收

统计每个类别的已付款成交额，游客也算。

<details>
<summary>展开参考答案</summary>

```sql
SELECT p.category, SUM(i.quantity * i.unit_price) AS revenue
FROM c5_orders AS o
JOIN c5_order_items AS i ON i.order_id = o.id
JOIN c5_products AS p ON p.id = i.product_id
WHERE o.status = 'paid'
GROUP BY p.category ORDER BY revenue DESC, p.category;
```

配件 400.00，食品 250.00。

</details>

### 练习 5 · 只看过门槛的组

上一题只保留成交额严格超过 300 元的类别。

<details>
<summary>展开参考答案</summary>

```sql
SELECT p.category, SUM(i.quantity * i.unit_price) AS revenue
FROM c5_orders AS o
JOIN c5_order_items AS i ON i.order_id = o.id
JOIN c5_products AS p ON p.id = i.product_id
WHERE o.status = 'paid' GROUP BY p.category
HAVING SUM(i.quantity * i.unit_price) > 300
ORDER BY revenue DESC, p.category;
```

配件一个组，400.00。

</details>

### 练习 6 · 上司和下属

给出宋言的两名直接下属。

<details>
<summary>展开参考答案</summary>

```sql
SELECT e.id, e.name FROM c5_staff AS e
JOIN c5_staff AS m ON m.id = e.manager_id
WHERE m.id = 1 ORDER BY e.id;
```

钱晓与吴青。条件使用经理主键。

</details>

### 练习 7 · 用 IN 找过付款的订单客户

回传注册客户编号，游客不在清单内。

<details>
<summary>展开参考答案</summary>

```sql
SELECT id FROM c5_customers
WHERE id IN (SELECT customer_id FROM c5_orders WHERE status = 'paid')
ORDER BY id;
```

1、2、3。外层客户行本身唯一。

</details>

### 练习 8 · 没有付款的客户

用 NOT EXISTS 找没有已付款订单的注册客户。

<details>
<summary>展开参考答案</summary>

```sql
SELECT c.id FROM c5_customers AS c
WHERE NOT EXISTS (
    SELECT 1 FROM c5_orders AS o WHERE o.customer_id = c.id AND o.status = 'paid'
)
ORDER BY c.id;
```

4、5。游客的 NULL 不会让内层误判匹配。

</details>

### 练习 9 · 最新的待付款或已付款订单

只考虑待付款或已付款，给每位注册客户找最新一单，时间并列取编号较大的。

<details>
<summary>展开参考答案</summary>

```sql
SELECT o.customer_id, o.id FROM c5_orders AS o
WHERE o.customer_id IS NOT NULL AND o.status IN ('paid', 'pending')
  AND NOT EXISTS (
      SELECT 1 FROM c5_orders AS other
      WHERE other.customer_id = o.customer_id AND other.status IN ('paid', 'pending')
        AND (other.ordered_at > o.ordered_at
          OR (other.ordered_at = o.ordered_at AND other.id > o.id))
  )
ORDER BY o.customer_id;
```

客户 1、2、3 分别是 102、104、105。

</details>

### 练习 10 · 两份编号清单

把杭州客户与有取消订单的客户合并成唯一编号清单。

<details>
<summary>展开参考答案</summary>

```sql
SELECT id AS customer_id FROM c5_customers WHERE city = '杭州'
UNION
SELECT customer_id FROM c5_orders WHERE status = 'cancelled' AND customer_id IS NOT NULL
ORDER BY customer_id;
```

1、3、4。用 UNION 表达唯一清单要求。

</details>

### 练习 11 · 业务题：品类订单数

给出每个商品类别的已付款订单数。一笔订单在同一类别里只数一次；跨类别则在每类各数一次。

<details>
<summary>展开参考答案</summary>

```sql
SELECT p.category, COUNT(DISTINCT o.id) AS orders
FROM c5_orders AS o
JOIN c5_order_items AS i ON i.order_id = o.id
JOIN c5_products AS p ON p.id = i.product_id
WHERE o.status = 'paid'
GROUP BY p.category ORDER BY p.category;
```

配件与食品各 3 笔。两类相加是 6，因为 105 同时含两类；全店实际只有 5 笔已付款订单。

</details>

### 练习 12 · 业务题：复购率的分母

在至少付款过一次的注册客户中，有多少比例付款两次或更多？显示分子、分母和百分比，分母若为 0 则百分比为空。

<details>
<summary>展开参考答案</summary>

```sql
SELECT COUNT(CASE WHEN paid.order_count >= 2 THEN 1 END) AS repeat_customers,
       COUNT(*) AS paying_customers,
       ROUND(100.0 * COUNT(CASE WHEN paid.order_count >= 2 THEN 1 END)
             / NULLIF(COUNT(*), 0), 2) AS repeat_pct
FROM (
    SELECT customer_id, COUNT(*) AS order_count
    FROM c5_orders WHERE status = 'paid' AND customer_id IS NOT NULL
    GROUP BY customer_id
) AS paid;
```

1 / 3，33.33%。待付款和取消不计入，游客没有注册客户号。

</details>
