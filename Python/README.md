## 怎么用这份教程

### 1. 按顺序读

```
01_基础语法 → 02_控制流 → 03_函数 → 04_数据结构 → ... → 12_模块与标准库
```

**不要跳着读**。后面的章节会用到前面的知识。

### 2. 每个文件的固定结构

```
┌─ 文件头：学习目标、怎么用、前置知识
├─ 知识点 1：讲解（【重点】【注意】【为什么】标注）+ 代码 + 输出
├─ 知识点 2：...
├─ ...
├─ 本章小结：核心知识点清单
└─ 动手练习：4 个练习题（附参考解法）
```

### 3. 两种读法

**读法 A：先读后跑**（推荐新手）
```powershell
# 1. 用 VS Code 打开文件，通读一遍
code "Python\01_基础语法\01_变量与数据类型.py"

# 2. 再运行看实际输出
python "Python\01_基础语法\01_变量与数据类型.py"
```

**读法 B：边跑边读**（推荐有基础的人）
```powershell
# 直接运行，输出滚动时对照代码看
python "Python\02_控制流\03_for循环.py"
```

## 学习建议

### 1. 一定要动手

**光读不写等于没学**。每个文件的「动手练习」都要自己做一遍，再对照参考解法。

### 2. 遇到不懂的问三处

```
1. Python 官方文档（中文）：https://docs.python.org/zh-cn/3/
2. 用 print() 打印中间结果调试
3. 用 VS Code 的调试器（F5）单步执行
```

### 3. 每学完一章就提交一次

```powershell
cd "D:\deepseek工作区\学习\cs学习\自学库"
git add Python/
git commit -m "docs: 完成第 X 章学习笔记"
git push
```

这样你的 GitHub 上会有完整的学习轨迹——**这是最好的作品集**。

### 4. 别怕改代码

**改坏一个文件试试！** 用 `git restore` 恢复就行。这是练习 Git 的最好方式。
