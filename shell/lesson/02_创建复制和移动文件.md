# 第 2 课｜创建、复制和移动文件

**用时约 45 分钟。** 从 `shell/` 开始，在 `practice/day1/` 创建一个文件，把副本移到另一个目录并改名。每做一步，先猜哪个路径会出现，再用 `ls` 验证。

## 1. 创建练习目录和文件

```bash
pwd
mkdir -p 'practice/day1'
cd 'practice/day1'
pwd
mkdir -p 'archive'
touch '空白 笔记.txt'
ls -l
```

第二次 `pwd` 应以 `/shell/practice/day1` 结尾。`mkdir -p` 会按需创建父目录，已有目录可以直接复用。`touch` 在文件不存在时创建空文件。文件已经存在时，`touch` 会更新时间戳，原来的内容还在。

## 2. 复制后检查两个文件

```bash
cp -i -- '空白 笔记.txt' '笔记 副本.txt'
ls -l -- '空白 笔记.txt' '笔记 副本.txt'
```

`cp` 的第一个路径是来源，第二个路径是目标。这里目标是一个新文件名，执行完应同时看到原文件和副本。`-i` 会在覆盖已存在的目标之前询问。重做时如果出现提示，输入 `n` 可以保留已有目标。

路径里有空格时，每条路径各用一对引号。`--` 表示后面都是路径参数，文件名以 `-` 开头时也会被当成文件名。

## 3. 移动和改名可以一步完成

```bash
mv -i -- '笔记 副本.txt' 'archive/已归档 笔记.txt'
ls -l
ls -l 'archive'
```

`mv` 同样先写来源，再写目标。两个目录相同时，它可以用来改名。这里目标路径的目录和文件名都变了，所以同时移动并改名。原件仍在 `day1`，副本现在应该在 `archive/已归档 笔记.txt`。

目标也可以写成**已经存在的目录**，比如 `archive/`。这种写法会沿用来源文件的名字。动手前先说出「它最后会落在哪个路径」，就能分清两种用法。

## 4. 独立练习

保持在 `practice/day1/`。新建 `review/` 和文件 `复习 草稿.txt`。把草稿复制到 `review/`，保留原名，再在 `review/` 内把副本改成 `复习 定稿.txt`。用 `ls` 验证原件和定稿各在哪里。

<details>
<summary>提示与参考答案</summary>

复制时可以把已存在的目录 `review/` 作为目标。改名时，来源和目标都写出 `review/`。

```bash
mkdir -p 'review'
touch '复习 草稿.txt'
cp -i -- '复习 草稿.txt' 'review/'
mv -i -- 'review/复习 草稿.txt' 'review/复习 定稿.txt'
ls -l -- '复习 草稿.txt' 'review/复习 定稿.txt'
```

</details>

**过关前，试着看懂**一个 `cp` 或 `mv` 命令，指出来源、目标和执行后应该出现的文件。然后自己操作一组带空格的路径，并用 `ls` 核对结果。
