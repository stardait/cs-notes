# 第 2 课｜创建、复制和移动文件

**用时约 45 分钟。** 你想留着一份原稿，再把它的副本移进归档目录并改名。从 `shell/` 开始。每次先写出你希望操作后有哪些路径，再决定用什么命令。

## 1. 先准备放东西的地方

要创建一个目录，用 `mkdir`。下面让它创建 `practice/day1`。`-p` 表示先补齐缺失的父目录，目标目录已经存在时也可以继续用。这样重做课程时，仍可以用同一句准备目录。

```bash
mkdir -p 'practice/day1'
cd 'practice/day1'
pwd
```

确认 `pwd` 以 `/shell/practice/day1` 结尾后，再创建 `archive` 和练习文件。`touch` 在路径不存在时会建一个空文件。已有文件时，它会更新时间戳并保留内容。`ls -l` 的 `-l` 让你看到更详细的列表，包括文件大小。

```bash
mkdir -p 'archive'
touch '空白 笔记.txt'
ls -l
```

## 2. 要留下原件，就用复制

先把需求写成两个路径。来源是 `空白 笔记.txt`，目标是 `笔记 副本.txt`。`cp` 按「来源、目标」的顺序收这两个路径。文件名有空格，因此第 1 课的引号规则要分别用在两个路径上。

```bash
cp -i '空白 笔记.txt' '笔记 副本.txt'
ls -l '空白 笔记.txt' '笔记 副本.txt'
```

两个名字应该都存在。`-i` 让 `cp` 在覆盖现有目标前询问。重做时看到提示，可以输入 `n` 保留已有副本。选项放在路径前面，说明要怎样复制。后面两个参数说明复制哪个文件、放到哪里。

## 3. 用目标路径表达「移动」「改名」或两者一起做

现在原件已经留好了，你希望副本只出现在 `archive` 中。`mv` 也按「来源、目标」收路径。把目标写成 `archive/已归档 笔记.txt`，前半段指定新位置，末尾指定新名字。

```bash
mv -i '笔记 副本.txt' 'archive/已归档 笔记.txt'
ls -l
ls -l 'archive'
```

预期原件还在 `day1`，而原来叫 `笔记 副本.txt` 的文件现在叫 `archive/已归档 笔记.txt`。如果把目标只写成已有目录 `archive/`，`mv` 会保留来源的名字。你可以先在纸上写出两种目标路径分别对应的最终文件位置。

**遇到文件名以 `-` 开头时。** 许多命令用 `-i` 这样的单词表示选项。假设文件叫 `-草稿.txt`，它也长得像选项。`--` 告诉下面这些命令「选项到这里结束」，后面的名字按路径处理。引号负责的是第 1 课讲过的参数边界。

```bash
touch -- '-草稿.txt'
ls -l -- '-草稿.txt'
```

## 4. 独立练习

保持在 `practice/day1/`。新建 `review/` 和文件 `复习 草稿.txt`。把草稿复制到 `review/`，保留原名，再在 `review/` 内把副本改成 `复习 定稿.txt`。用 `ls` 验证原件和定稿各在哪里。

<details>
<summary>提示与参考答案</summary>

复制时可以把已存在的目录 `review/` 作为目标。改名时，来源和目标都写出 `review/`。

```bash
mkdir -p 'review'
touch '复习 草稿.txt'
cp -i -- '复习 草稿.txt' 'review/'
mv -i -- 'review/复习 草稿.txt' 'review/复习 定稿.txt'
ls -l -- '复习 草稿.txt' 'review/复习 定稿.txt'
```

</details>

**过关前，试着看懂**一个 `cp` 或 `mv` 命令，指出来源、目标和执行后应该出现的文件。然后自己操作一组带空格的路径，并用 `ls` 核对结果。

练完从 `practice/day1/` 用 `cd ../..` 回到 `shell/`。第 3 课会在 `practice/day2/` 准备后续几课共用的日志。
