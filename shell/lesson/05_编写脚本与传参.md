# 第 5 课｜编写脚本与传参

**用时约 50 分钟。** 从 `shell/` 开始，把「查看某个日志的开头」做成 `scripts/show_log.sh`。脚本接收一个路径，换日志时换参数即可。需要样本时，先按 [第 3 课](03_查找文件与搜索内容.md) 创建 `session.log`。

## 1. 理解调用命令的两部分

你平时会手敲这样的命令。

```bash
head -n 3 'practice/day2/session.log'
```

把它写进脚本时，可以把文件路径从外面传进来，就像调用 Python 函数时给它一个参数。运行 `bash scripts/show_log.sh 'practice/day2/session.log'` 时，Bash 读取 `show_log.sh`，后面的日志路径成为脚本的第一个参数。

- `$0` 在这里是脚本的调用路径。
- `$#` 是传给脚本的参数个数。
- `$1` 是第一个参数，`$2` 是第二个参数。

## 2. 保存第一个脚本

用编辑器在 `scripts/` 创建 `show_log.sh`，保存为 **UTF-8、LF 换行**。下面整段是文件内容。

```bash
#!/usr/bin/env bash

if [[ $# -ne 1 ]]; then
    printf '用法：bash %s 日志路径\n' "$0" >&2
    exit 2
fi

log=$1
printf '日志路径：%s\n' "$log"
head -n 3 < "$log"
```

- 首行声明用 Bash 解释这个脚本。我们直接用 `bash 文件名` 来运行。
- `[[ $# -ne 1 ]]` 检查参数个数是否不等于 1。参数数量错时，`>&2` 把用法说明送到标准错误，`exit 2` 结束这次运行。下一课会练习检查这个状态。
- `log=$1` 把第一个参数存进变量，等号两边不能有空格。`"$log"` 展开变量并保留整个路径，哪怕文件名里有空格。
- 最后一行复用了上一课的 `<`。由 Bash 打开路径，从这个文件给 `head` 提供输入。

## 3. 先检查语法，再执行

回到 `shell/`，逐条运行。

```bash
bash -n 'scripts/show_log.sh'
bash 'scripts/show_log.sh' 'practice/day2/session.log'
```

`bash -n` 检查 Bash 语法，成功时通常无输出。实际运行应先显示日志路径，再显示日志的前三行，从 `INFO start` 到 `INFO retry`。实际运行才能验证路径和输入数据。

如果看到类似 `$'\r': command not found` 的消息，检查编辑器里脚本的换行模式，把 CRLF 改为 LF 后再保存。

## 4. 验证带空格的路径

```bash
cp -i -- 'practice/day2/session.log' 'practice/day2/session copy.log'
bash 'scripts/show_log.sh' 'practice/day2/session copy.log'
bash 'scripts/show_log.sh' practice/day2/session copy.log
```

复制出现覆盖提示时，如果已有副本就是课程样本，可以输入 `n` 继续。第二条应读到与原样本相同的内容。第三条特意省略了引号，Bash 会把 `practice/day2/session` 和 `copy.log` 拆成两个参数，脚本因此显示用法。调用处的引号负责把路径传成一个参数，脚本里的双引号负责在使用变量时保留它。

## 5. 独立练习

1. 把脚本改成只显示前 2 行，先用 `bash -n` 检查，再用含空格的路径运行。
2. 空着路径参数运行一次，确认脚本会给出用法。再恢复正常参数，确认脚本能继续读文件。
3. 解释如果把打印路径那行的 `"$log"` 改成 `'$log'`，屏幕上会出现什么。

<details>
<summary>参考答案与检查</summary>

把最后一行改为 `head -n 2 < "$log"`。正常输出的两条日志应是 `INFO start` 和 `ERROR cannot open file`。只运行 `bash 'scripts/show_log.sh'` 时，`$#` 为 `0`，因此会给出用法。`'$log'` 会传入字面文字 `$log`，双引号中的 `"$log"` 才会展开变量。

</details>

**过关标准**

能自己保存并运行脚本，用同一份脚本读取两个不同路径，并解释为什么含空格的路径在调用处和脚本里都需要引用。
