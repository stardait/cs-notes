# 第 1 课｜当前目录与相对路径

**用时约 25 分钟。** 假设你想打开 `学习计划.md`，Git Bash 却刚启动。先弄清 Bash 从哪里找文件，再决定给它哪条路径。

## 1. 电脑里有这个文件，为什么命令还会找不到？

在资源管理器里，「打开这个文件」往往隐含了「在我正看着的这个文件夹里找」。Git Bash 也有这样的起点，叫**当前工作目录**。每个终端会话可以处在不同目录。

打开 **Git Bash**，先只敲这一条。若你从 PowerShell 启动，运行 `& 'F:/Scoop/apps/git/current/bin/bash.exe'` 会进入 Bash。

```bash
pwd
```

`pwd` 打印当前位置。它显示的路径就是接下来短路径的起点。要从任意位置到同一个地方，给 `cd` 一条从根目录 `/` 开始的完整路径，也就是**绝对路径**。在你这套 Git Bash 里，Windows 的 `D:\` 对应 `/d/`。

```bash
cd '/d/deepseek工作区/学习/cs学习/自学库/shell'
pwd
ls
```

可以按空格分开的两部分读第一行。`cd` 是要执行的命令，后面引号包住的整条路径是它收到的参数。换好目录后，`pwd` 验证位置，`ls` 列出这里有哪些东西。你应该看到 `lesson`、`practice`、`notes`、`scripts`、`backups` 和 `学习计划.md`。

## 2. 同一个名字，换一个起点会指到哪里？

`practice` 就在当前目录下面，写完整路径会重复一次 `pwd` 已经知道的信息。把名字直接交给 `cd`，就是从当前位置找它。这样的写法叫**相对路径**。`.` 代表这里，所以 `./practice` 明确写出了起点。`..` 代表上一级。

```bash
cd practice
pwd
cd ..
pwd
```

想象自己在下面这棵树里走。进入 `practice` 后，第一次 `pwd` 应以 `/shell/practice` 结尾。`cd ..` 向上走一级，第二次回到 `/shell`。

```text
自学库/
├── 数据库/
└── shell/
    ├── 学习计划.md
    ├── lesson/
    └── practice/
```

从 `practice` 看，计划要向上一级才找得到。`../学习计划.md` 可以读成「先上一级，再找这个文件」。

## 3. 用一次失败验证自己的判断

现在在 `shell`。想只读计划前 5 行，就叫 `head` 读取文件，用选项 `-n 5` 指定行数，再给它文件路径。先预测这条命令在两个目录里会分别找到哪里。

```bash
head -n 5 '学习计划.md'
cd practice
pwd
head -n 5 '学习计划.md'
```

第一次从 `shell` 找，能显示前 5 行。第二次从 `shell/practice` 找，通常会报 `No such file or directory`。保持当前位置，只改最后一个参数。

```bash
head -n 5 '../学习计划.md'
pwd
cd ..
```

这回能读到，而 `pwd` 仍显示 `/shell/practice`。`head` 用路径找到并读取文件。要改变当前工作目录，要执行 `cd`。

以后碰到文件找不到，先跑 `pwd`，再根据文件实际位置修正路径。Python 里的 `Path('data.csv').read_text()` 也会从进程的当前工作目录查找相对路径。

## 4. 为什么文件名有空格时要加引号？

Bash 会把未加引号的空格当作参数的边界。用 `printf` 看清边界。`<%s>` 会把一个值放进尖括号，`\n` 在末尾换行。有几个值，下面的格式就重复几次。

```bash
printf '<%s>\n' 学习 笔记.md
printf '<%s>\n' '学习 笔记.md'
```

第一条收到两个值，打印 `<学习>` 和 `<笔记.md>`。第二条收到一个值，打印 `<学习 笔记.md>`。引号帮助 Bash 确定参数从哪里开始、到哪里结束。传给命令的是引号里面的文字。

## 5. 独立练习

1. 从 `shell` 出发，只用相对路径进入同级的 `数据库`。用 `pwd` 验证，再用相对路径返回 `shell`。
2. 进入 `lesson`，保持当前位置，用一条 `head` 命令显示 `学习计划.md` 的前 3 行。
3. 口头解释第 2 题的路径从哪儿开始算，以及 `head` 执行后你还在哪个目录。

<details>
<summary>提示与参考答案</summary>

第 1 题先找 `shell` 和 `数据库` 的共同父目录。第 2 题可以在 `lesson` 中先用 `ls ..` 确认上一级有哪些内容。

```bash
cd '../数据库'
pwd
cd '../shell'
cd lesson
head -n 3 '../学习计划.md'
pwd
cd ..
```

第 1 次 `pwd` 以 `/自学库/数据库` 结尾。第 2 次以 `/shell/lesson` 结尾。第二题里的 `..` 从 `lesson` 往上走到 `shell`，`head` 读取其中的 `学习计划.md`。
