# 第 1 课｜当前目录与相对路径

**用时约 25 分钟。** 学完后，你能在 Git Bash 里判断自己在哪、用相对路径进入另一个目录、打开指定文件，并能解释同一条命令为什么换个目录就可能失败。

## 1. 先定位，再行动

打开 **Git Bash**。也可以在 PowerShell 里运行 `& 'F:/Scoop/apps/git/current/bin/bash.exe'` 进入 Bash。接下来逐行输入，每行敲完回车，先看结果再走下一步。

```bash
pwd
cd '/d/deepseek工作区/学习/cs学习/自学库/shell'
pwd
ls
```

- `pwd` 回答「我现在在哪？」它打印当前工作目录。第一次的输出取决于你从哪里打开 Git Bash。
- `cd` 回答「我要去哪？」它改变当前目录。执行成功时通常没有输出，接着用 `pwd` 验证。
- `ls` 回答「这里有什么？」进入 `shell` 后，你应该看到 `lesson`、`practice`、`notes`、`scripts`、`backups` 和 `学习计划.md`。

Windows 的 `D:\` 在这套 Git Bash 中写成 `/d/`。上面给 `cd` 的路径从 `/d/` 开始，完整写到了 `shell`。这种从根目录 `/` 开始的路径叫**绝对路径**。不管第一次 `pwd` 显示什么，都能用它回到同一个位置。

## 2. 用当前目录当起点

你现在在 `shell`。敲之前先猜两次 `pwd` 的末尾分别是什么。

```bash
cd practice
pwd
cd ..
pwd
```

第一次应以 `/shell/practice` 结尾，第二次应以 `/shell` 结尾。`practice` 是**相对路径**。Bash 从当前目录找名叫 `practice` 的子目录。`..` 表示当前目录的上一级，`.` 表示当前目录本身。因此这里的 `cd ./practice` 和 `cd practice` 都能进入练习目录。

这是你所在位置附近的目录关系。

```text
自学库/
├── 数据库/
└── shell/
    ├── 学习计划.md
    ├── lesson/
    └── practice/
```

从 `practice` 看，学习计划在上一级。把 `../学习计划.md` 念成「先上一级，再找这个文件」。

## 3. 看一次错误，再把它修好

你现在在 `shell`。运行 `head -n 5`，读取指定文件的前 5 行。

```bash
head -n 5 '学习计划.md'
cd practice
pwd
head -n 5 '学习计划.md'
```

第二次 `head` 预计会报 `No such file or directory`。它这次从 `shell/practice` 找 `学习计划.md`，文件实际在上一级。保持当前目录，试试修正路径。

```bash
head -n 5 '../学习计划.md'
pwd
cd ..
```

文件能读到，`pwd` 仍以 `/shell/practice` 结尾。`head` 可以用路径读取别处的文件。切换工作目录靠的是 `cd`。

以后碰到文件找不到，先跑 `pwd`，再用 `ls` 看当前目录，最后根据文件的实际位置修正路径。这个习惯也适用于 Python。比如 `Path('data.csv').read_text()` 会从程序的当前工作目录找 `data.csv`。

## 4. 文件名有空格时加引号

下面用 `printf` 观察 Bash 怎样分参数。这里的格式会给后面的每个值套一对尖括号，方便数清楚。

```bash
printf '<%s>\n' 学习 笔记.md
printf '<%s>\n' '学习 笔记.md'
```

第一条打印两行，`<学习>` 和 `<笔记.md>`。第二条打印一行 `<学习 笔记.md>`。以后遇到带空格的固定路径，像第二条一样用引号把路径包成一个参数。

## 5. 独立练习

1. 从 `shell` 出发，只用相对路径进入同级的 `数据库`。用 `pwd` 验证，再用相对路径返回 `shell`。
2. 进入 `lesson`，保持当前位置，用一条 `head` 命令显示 `学习计划.md` 的前 3 行。
3. 口头解释第 2 题的路径从哪儿开始算，以及 `head` 执行后你还在哪个目录。

<details>
<summary>提示与参考答案</summary>

第 1 题先找 `shell` 和 `数据库` 的共同父目录。第 2 题可以在 `lesson` 中先用 `ls ..` 确认上一级有哪些内容。

```bash
cd '../数据库'
pwd
cd '../shell'
cd lesson
head -n 3 '../学习计划.md'
pwd
cd ..
```

第 1 次 `pwd` 以 `/自学库/数据库` 结尾。第 2 次以 `/shell/lesson` 结尾。第二题里的 `..` 从 `lesson` 往上走到 `shell`，`head` 读取其中的 `学习计划.md`。

</details>

**过关标准**：能独立在两个同级目录之间往返。遇到找不到文件时，能根据 `pwd` 指出命令刚才从哪里找，并写出正确的相对路径。
