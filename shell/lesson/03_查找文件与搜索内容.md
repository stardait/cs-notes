# 第 3 课｜查找文件与搜索内容

**用时约 45 分钟。** 从 `shell/` 开始。你会用 `find` 按文件名找文件，用 `grep` 在文件里找匹配的行。想想你在数据库笔记中找 `JOIN` 时，应该查的是文件名还是文件内容。

## 1. 准备后续几课共用的练习日志

```bash
mkdir -p 'practice/day2'
printf '%s\n' \
  'INFO start' \
  'ERROR cannot open file' \
  'INFO retry' \
  'ERROR database timeout' \
  'WARN slow query' > 'practice/day2/session.log'
cat 'practice/day2/session.log'
```

`printf` 把每个参数写成一行。这里的 `>` 把结果存进 `session.log`，重跑这段会把课程样本恢复成这五行。下一课会专门讲这个符号。后面的例子都从 `shell/` 运行，所以路径里保留了 `practice/day2/`。

## 2. 用 `find` 按文件名查找

```bash
find 'practice/day2' -type f -name '*.log'
```

从第一个路径开始往下找。`-type f` 筛出普通文件，`-name '*.log'` 筛出文件名以 `.log` 结尾的文件。这个命令应找到 `practice/day2/session.log`。给 `*.log` 加引号，让 `find` 拿到原样的匹配模式。如果漏掉引号，Bash 可能提前把它展开成当前目录里的文件名。

## 3. 用 `grep` 查文件内容

```bash
grep -nF -- 'timeout' 'practice/day2/session.log'
grep -n -- '^ERROR ' 'practice/day2/session.log'
```

第一条应显示第 4 行。`-n` 加上行号，`-F` 按字面文字搜索。第二条应显示第 2 行和第 4 行。这里 `^` 表示行首，`ERROR` 后的空格也是匹配条件。这条用了一个最小的正则表达式，保留 `^` 的特殊含义需要省略 `-F`。

你可以把这次筛选类比成 SQL 的 `WHERE`。这里筛选的是文本文件里的整行，每条日志恰好占一行。

## 4. 用自己的数据库笔记做一次搜索

```bash
find '../数据库' -type f -name '*.md'
grep -rnF --include='*.md' -- 'JOIN' '../数据库'
```

先预测第一条会列出什么，再跑第二条。`-r` 让 `grep` 递归搜索目录，`--include='*.md'` 把搜索范围限定在 Markdown 文件。结果通常包含文件路径、行号和匹配内容。想缩小结果，可以把 `../数据库` 换成用 `ls '../数据库'` 找到的某个章节路径。

## 5. 独立练习

1. 在 `practice/` 下面找出所有名为 `session.log` 的文件。
2. 找到样本中以 `WARN ` 开头的行，显示行号。先猜它在第几行。
3. 在数据库 Markdown 笔记里搜索 `WHERE`。找一个结果，说出你会打开哪个文件、去看第几行。

```bash
find 'practice' -type f -name 'session.log'
grep -n -- '^WARN ' 'practice/day2/session.log'
grep -rnF --include='*.md' -- 'WHERE' '../数据库'
```

**过关标准**

遇到「文件在哪」能用 `find`，遇到「哪一行写了这个词」能用 `grep`。能解释 `grep -F` 搜索的字面文本和 `^` 行首匹配的区别。
