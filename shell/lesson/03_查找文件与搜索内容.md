# 第 3 课｜查找文件与搜索内容

**用时约 45 分钟。** 从 `shell/` 开始。想找「哪个文件叫 `session.log`」时，需要检查文件名。想知道「哪里提到 `timeout`」时，需要打开文件检查每一行。先判断你要找哪一种东西，再选命令。

## 1. 用五行文字准备样本

如果已经有 `practice/day2/session.log`，可以直接用 `cat 'practice/day2/session.log'` 确认内容。需要恢复课程样本时，运行下面的例子。第 1 课的 `printf '%s\n'` 会把每个字符串写成一行。末尾的 `>` 把输出写进文件，重跑会覆盖这个课程样本。多行命令里的行末反斜杠告诉 Bash 命令还没结束。

```bash
mkdir -p 'practice/day2'
printf '%s\n' \
  'INFO start' \
  'ERROR cannot open file' \
  'INFO retry' \
  'ERROR database timeout' \
  'WARN slow query' > 'practice/day2/session.log'
cat 'practice/day2/session.log'
```

预期看到五行。`cat` 会把文件内容送到屏幕。下一课会把同一份输出接到别的地方。

## 2. 用 `find` 把搜索范围一点点缩小

先告诉 `find` 从哪个目录开始。它往下遍历，默认会打印遇到的路径。只想看文件时加 `-type f`，再用 `-name` 限制名字。

```bash
find 'practice/day2'
find 'practice/day2' -type f
find 'practice/day2' -type f -name '*.log'
```

最后一条可以读成「从 `practice/day2` 开始，找普通文件，名字以 `.log` 结尾」。`-type` 后面的 `f` 和 `-name` 后面的 `*.log` 分别是各自条件的值。最后应该能看到 `practice/day2/session.log`。

为什么给 `*.log` 加引号？你希望 `find` 把这个模式应用到每个候选文件上。未加引号的 `*` 有机会被 Bash 先展开成当前目录里已有的文件名。拿当前目录里一定存在的 Markdown 文件试一遍。

```bash
printf '<%s>\n' *.md
printf '<%s>\n' '*.md'
```

第一条会显示实际文件名，例如 `学习计划.md`，第二条把 `*.md` 原样交给 `printf`。同样，给 `find` 加引号就把匹配工作留给 `find`。

## 3. 同一个词，可以要求「包含」或「开头就是」

先找包含单词 `timeout` 的记录。`grep` 接收「匹配条件、文件路径」。用 `-F` 让它按字面理解这个词，用 `-n` 让结果带行号。`--` 沿用上节的选项结束标记。

```bash
grep -nF -- 'timeout' 'practice/day2/session.log'
```

预期第 4 行。现在假设正文里也可能提到 `ERROR`。如果我们想按日志级别筛选，就要要求这个词出现在行首。用一个单独的练习文件把差别放大。

```bash
printf '%s\n' 'INFO cleared ERROR from yesterday' 'ERROR database timeout' > 'practice/day2/pattern-demo.log'
grep -nF -- 'ERROR' 'practice/day2/pattern-demo.log'
grep -n -- '^ERROR ' 'practice/day2/pattern-demo.log'
```

字面搜索会找到两行。最后一条只找到第 2 行。`^` 在 `grep` 的正则表达式中表示行首，`ERROR` 后面的空格也参与匹配。引号把模式原样交给 `grep`，省掉 `-F` 才会让 `grep` 按正则解释 `^`。再把这个条件用回主样本。

```bash
grep -n -- '^ERROR ' 'practice/day2/session.log'
```

应该找到第 2 和第 4 行。可以用 SQL 的 `WHERE` 来理解这个过程，每行文本是一个候选记录，模式决定哪些行留下。

## 4. 把单文件搜索扩大到自己的数据库笔记

`../数据库` 是第 1 课练过的同级目录。`find` 负责列出 Markdown 文件路径。要查文件里的 `JOIN`，让 `grep` 用 `-r` 逐层进子目录，再用 `--include='*.md'` 限定要检查的文件名。`-rnF` 合写了 `-r`、`-n` 和 `-F`。

```bash
find '../数据库' -type f -name '*.md'
grep -rnF --include='*.md' -- 'JOIN' '../数据库'
```

挑第二条的一项结果拆开看，依次是文件路径、行号和匹配内容。如果结果太多，可以把最后的目录换成某一章。

## 5. 独立练习

1. 在 `practice/` 下面找出所有名为 `session.log` 的文件。
2. 找到样本中以 `WARN ` 开头的行，显示行号。先猜它在第几行。
3. 在数据库 Markdown 笔记里搜索 `WHERE`。找一个结果，说出你会打开哪个文件、去看第几行。

```bash
find 'practice' -type f -name 'session.log'
grep -n -- '^WARN ' 'practice/day2/session.log'
grep -rnF --include='*.md' -- 'WHERE' '../数据库'
```

**过关标准**

遇到「文件在哪」能用 `find`，遇到「哪一行写了这个词」能用 `grep`。能解释 `grep -F` 搜索的字面文本和 `^` 行首匹配的区别。
